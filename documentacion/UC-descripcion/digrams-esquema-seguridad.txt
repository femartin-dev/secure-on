A continuación, se presentan los diagramas en PlantUML (código ejecutable) y los bosquejos en texto ASCII para los casos de uso UC-020, UC-021 y UC-022, siguiendo la metodología del Proceso Unificado de Desarrollo de Software.

UC-020: Registrar Usuario
1. Diagrama de Actividad (PlantUML)
plantuml
@startuml
|Usuario|
start
:Selecciona "Crear cuenta";
|Sistema|
:Mostrar formulario con campos obligatorios,
opcionales y términos;
|Usuario|
:Completa campos y acepta términos;
|Sistema|
:Validar datos obligatorios y formato;
if (¿Datos válidos?) then (Sí)
  :Habilitar botón Registrar;
  |Usuario|
  :Presiona "Registrar";
  |Sistema|
  :Verificar si email o teléfono ya registrados;
  if (¿Ya registrado?) then (Sí)
    if (Email registrado?) then (Sí)
      :Notificar error y ofrecer corregir email o recuperar contraseña;
      |Usuario|
      if (Usuario elige?) then (Cambiar email)
        :Cambia email;
        -->|Vuelve a verificar| "Verificar si email o teléfono ya registrados";
      else (Recuperar contraseña)
        :Ejecutar UC-025;
        stop
      endif
    else (Teléfono registrado)
      :Notificar error y ofrecer corregir teléfono o desvincular;
      |Usuario|
      if (Usuario elige?) then (Cambiar teléfono)
        :Cambia teléfono;
        -->|Vuelve a verificar| "Verificar si email o teléfono ya registrados";
      else (Desvincular teléfono)
        :Ejecutar UC-026;
        if (Desvinculación exitosa?) then (Sí)
          |Sistema|
          :Guardar datos transitoriamente (pendiente);
        else (No)
          :Mostrar error;
          stop
        endif
      endif
    endif
  else (No registrado)
    :Guardar datos transitoriamente (pendiente);
    :Enviar código de verificación por email;
    :Mostrar campo para código y opción reenviar;
    |Usuario|
    :Introduce código recibido;
    |Sistema|
    :Validar código;
    if (Código correcto?) then (Sí)
      :Cambiar estado cuenta a "activa";
      :Ejecutar UC-026 (registrar teléfono);
      :Ejecutar UC-017 (configuraciones iniciales);
      :Fin;
      stop
    else (No)
      :Notificar error;
      -->|Volver a mostrar campo código| "Mostrar campo para código y opción reenviar";
    endif
  endif
else (No)
  :Mostrar mensajes de error por campo;
  -->|Vuelve al formulario| "Mostrar formulario...";
endif
@enduml

UC-021: Iniciar Sesión Usuario
1. Diagrama de Actividad (PlantUML)
plantuml
@startuml
|Usuario|
start
:Abre la app (no autenticado);
|Sistema|
:Mostrar formulario login;
|Usuario|
:Ingresa credenciales y pulsa "Iniciar Sesión";
|Sistema|
:Validaciones básicas de formato;
if (Formato correcto?) then (No)
  :Mostrar error, aumentar contador fallos;
  if (Contador >= 3?) then (Sí)
    :Bloquear 3 minutos;
  endif
  -->|Volver a mostrar formulario| "Mostrar formulario login";
else (Sí)
  :Verificar existencia de cuenta;
  if (Cuenta existe?) then (No)
    :Mostrar error, aumentar contador fallos;
    if (Contador >= 3?) then (Sí)
      :Bloquear 3 minutos;
    endif
    -->|Volver a mostrar formulario| "Mostrar formulario login";
  else (Sí)
    :Llamar a Servicio de Autenticación;
    if (Credenciales válidas?) then (No)
      :Mostrar error, aumentar contador fallos;
      if (Contador >= 3?) then (Sí)
        :Bloquear 3 minutos;
      endif
      -->|Volver a mostrar formulario| "Mostrar formulario login";
    else (Sí)
      :Recibir token y datos perfil;
      :Guardar token cifrado;
      :Sincronizar configuración dispositivo;
      if (Dispositivo ya vinculado?) then (No)
        :Ejecutar UC-024 (registrar dispositivo);
      endif
      :Cerrar interfaz login;
      :Redirigir a pantalla principal;
      stop
    endif
  endif
endif
@enduml

UC-022: Cerrar Sesión Usuario
1. Diagrama de Actividad (PlantUML)
plantuml
@startuml
|Usuario|
start
:Accede a menú de perfil y selecciona "Cerrar Sesión";
|Sistema|
:Mostrar diálogo de confirmación;
|Usuario|
if (Opción elegida?) then (Cancelar)
  |Sistema|
  :Volver a perfil;
  stop
else if (Cerrar sesión normal)
  |Usuario|
  :Confirma "Cerrar sesión";
  |Sistema|
  :Enviar solicitud de invalidación al servicio de autenticación;
  :Eliminar token local del almacenamiento;
  :Limpiar datos sensibles de memoria;
  :Redirigir a pantalla de inicio de sesión;
  :Mostrar mensaje de confirmación;
  stop
else (Cerrar en todos los dispositivos)
  |Usuario|
  :Selecciona "Cerrar en todos los dispositivos";
  |Sistema|
  :Buscar todos los dispositivos vinculados a la cuenta;
  :Para cada dispositivo, enviar invalidación al servicio de autenticación;
  :Eliminar token local;
  :Limpiar datos sensibles;
  :Redirigir a login;
  :Mostrar mensaje;
  stop
endif
@enduml
