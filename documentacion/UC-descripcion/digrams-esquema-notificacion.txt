Aquí tienes el análisis completo para el UC-009 Enviar Alarma a Contactos, desarrollado según la metodología del Proceso Unificado de Jacobson, Booch y Rumbaugh. Se incluyen los diagramas en formato PlantUML y sus correspondientes bosquejos textuales para facilitar su comprensión.

🧩 Identificación de Clases de Análisis (Patrón ECB)
Clase	Estereotipo	Responsabilidad
ServicioMensajeriaExterno	A (Actor Secundario)	APIs externas de WhatsApp, Telegram, SMS que reciben y procesan los mensajes.
ContactoEmergencia	A (Actor Secundario implícito)	Destinatario de los mensajes de alarma.
InterfazNotificacionContactos	I (Interfaz)	Punto de entrada invocado por el UC-001 para iniciar el envío de notificaciones.
ControlEnvioAlarmaContactos	C (Controlador)	Orquesta el proceso: recupera contactos, construye mensajes, selecciona canales, envía notificaciones y gestiona fallos.
ControlCanalMensajeria	C (Controlador)	Maneja la comunicación específica con cada API externa (WhatsApp, Telegram, SMS directo).
ControlReintentos	C (Controlador)	Delegado para manejar fallos de envío mediante el UC-011 (Gestor de Reintentos).
GestorAlarma	C (Controlador)	Contexto de la alarma activa que proporciona datos como ubicación y timestamp.
PerfilUsuario	E (Entidad)	Almacena la lista de contactos de emergencia y sus preferencias de canal.
HistorialEnvios	E (Entidad)	Registra el estado de cada envío (exitoso, fallido, pendiente).

Formal (PlantUML)

:Sistema recupera lista de contactos de emergencia del perfil;
:Sistema verifica si hay contactos configurados;

  stop
else (Sí)
  :Sistema itera sobre cada contacto;
  :Sistema obtiene canal preferido del contacto;
  if (¿Canal definido?) then (No)
    :Sistema asigna SMS por defecto;
  endif
  :Sistema construye mensaje personalizado\n(nombre, mensaje predefinido, ubicación, hora);
  :Sistema verifica conexión a internet;
  if (¿Conexión disponible?) then (No)
    :Sistema invoca UC-011 (modo falloCTO) en paralelo;
  else (Sí)
    if (¿Canal es SMS?) then (Sí)
      :Sistema invoca UC-011 (modo falloCTO) en paralelo;
    else (No)
      :Sistema envía mensaje a través de API del servicio de mensajería;
      if (¿API retorna error?) then (Sí)
        :Sistema invoca UC-011 (modo falloCTO) en paralelo;
      else (No)
        :Sistema registra envío exitoso en historial;
      endif
    endif
  endif
  :Sistema verifica si hay más contactos;
  if (¿Más contactos?) then (Sí)
    -> vuelve a "Sistema itera sobre cada contacto";
  endif
  stop
endif
@enduml

2. Diagrama de Estado
Formal (PlantUML)
Enfocado en el estado del proceso de envío para un contacto individual.

plantuml
@startuml
[*] --> Preparando

state Preparando {
  [*] --> RecuperandoContacto
  RecuperandoContacto --> ConstruyendoMensaje : contactoObtenido()
  ConstruyendoMensaje --> VerificandoConectividad : mensajeListo()
}

state VerificandoConectividad {
  [*] --> EvaluandoConexion
  EvaluandoConexion --> SinConexion : noInternet
  EvaluandoConexion --> ConConexion : internetDisponible
  SinConexion --> DelegandoReintento
  ConConexion --> SeleccionandoCanal
}

state SeleccionandoCanal {
  [*] --> CanalSMS : canal == SMS
  [*] --> CanalApp : canal en {WhatsApp, Telegram}
  CanalSMS --> DelegandoReintento
  CanalApp --> EnviandoAPI
}

state EnviandoAPI {
  [*] --> EsperandoRespuesta
  EsperandoRespuesta --> EnvioExitoso : respuesta 200 OK
  EsperandoRespuesta --> ErrorAPI : respuesta error
  ErrorAPI --> DelegandoReintento
}

state DelegandoReintento {
  [*] --> InvocandoUC011
  InvocandoUC011 --> PendienteReintento : programado()
  PendienteReintento --> [*]
}

state EnvioExitoso {
  [*] --> RegistrandoHistorial
  RegistrandoHistorial --> [*]
}
@enduml

  end

  end

🧩 Identificación de Clases de Análisis (Patrón ECB)
Clase	Estereotipo	Responsabilidad
ServicioNotificaciones	A (Actor Secundario)	Servidor del Centro de Monitoreo que recibe y procesa los datos de la alarma.
InterfazTransmisionCdM	I (Interfaz)	Punto de entrada invocado por UC-001 para iniciar la transmisión al CdM.
ControlTransmisionCdM	C (Controlador)	Orquesta el proceso: establece conexión, envía paquete inicial, gestiona transmisión periódica de ubicación y evidencias, maneja reconexiones y reintentos.
ControlConexionCdM	C (Controlador)	Maneja la conexión de red con el servidor del CdM, timeouts y reconexiones.
ControlBufferTransmision	C (Controlador)	Almacena en buffer local los datos cuando no hay conexión y los sincroniza al reconectar.
ControlReintentos	C (Controlador)	Delegado para manejar fallos de conexión mediante el UC-011.
GestorAlarma	C (Controlador)	Contexto de la alarma activa que proporciona datos del usuario, ubicación y estado.
PerfilUsuario	E (Entidad)	Almacena los datos del usuario registrado (ID, nombre, contacto).
ColaEvidencias	E (Entidad)	Gestiona la cola de evidencias (audio, fotos) pendientes de envío.
ConfiguracionTransmision	E (Entidad)	Almacena parámetros de transmisión (intervalo de ubicación, timeout de reconexión).
HistorialTransmisiones	E (Entidad)	Registra eventos de transmisión (conexiones, reconexiones, envíos exitosos).
1. Diagrama de Actividad
Formal (PlantUML)
plantuml
@startuml
|Sistema|
|CdM|
start
:Sistema establece conexión con servidor del CdM;
if (¿Conexión exitosa?) then (No)
  :Sistema ejecuta UC-011 (modo falloCdM);
  stop
else (Sí)
  if (¿Modo activación?) then (Sí)
    :Sistema envía paquete inicial:\n- Datos del usuario\n- Ubicación actual\n- Timestamp\n- Método de activación;
  else (No)
    :Sistema envía paquete con:\n- ID de alarma\n- Estado\n- Ubicación\n- Timestamp;
  endif
  
  :Sistema espera confirmación del CdM (timeout 5s);
  if (¿Confirmación recibida?) then (No)
    :Sistema incrementa contador de intentos;
    if (¿Intentos <= 3?) then (Sí)
      :Sistema espera 5 segundos;
      -> vuelve a "Sistema envía paquete";
    else (No)
      :Sistema ejecuta UC-011 (modo falloCdM);
      stop
    endif
  else (Sí)
    :Sistema recibe ID de alarma, operador asignado e instrucciones;
    :Sistema inicia transmisión periódica de ubicación (cada 30s);
    :Sistema comienza a enviar evidencias de la cola pendiente;
    
    fork
      :Sistema transmite ubicación periódicamente;
      if (¿Pérdida de conexión?) then (Sí)
        :Sistema almacena en buffer local;
        :Sistema reintenta reconexión (5s, hasta 3 intentos);
        if (¿Reconexión exitosa?) then (Sí)
          :Sistema sincroniza datos pendientes;
          -> vuelve a transmisión;
        else (No)
          :Sistema ejecuta UC-011 (modo falloGPS);
          stop
        endif
      endif
    fork again
      :Sistema envía evidencias;
      if (¿Pérdida de conexión?) then (Sí)
        :Sistema almacena en buffer local;
        :Sistema reintenta reconexión (5s, hasta 3 intentos);
        if (¿Reconexión exitosa?) then (Sí)
          :Sistema sincroniza evidencias pendientes;
          -> vuelve a envío;
        else (No)
          :Sistema ejecuta UC-011 (modo falloEVD);
          stop
        endif
      else (Sí)
        :Sistema marca evidencias como enviadas;
      endif
    end fork
    
    :Sistema verifica estado de alarma;
    if (¿Alarma finalizada?) then (Sí)
      :Sistema cierra conexión con CdM;
      stop
    else (No)
      -> vuelve a transmisión periódica;
    endif
  endif
endif

2. Diagrama de Estado
Formal (PlantUML)
Enfocado en el estado de la transmisión al Centro de Monitoreo.

plantuml
@startuml
[*] --> Desconectado

state Desconectado {
  [*] --> IntentandoConexion
  IntentandoConexion --> Conectado : conexionExitosa()
  IntentandoConexion --> FalloConexion : intentos > 3
  FalloConexion --> [*] : UC-011 falloCdM
}

state Conectado {
  [*] --> EnviandoPaqueteInicial
  EnviandoPaqueteInicial --> EsperandoConfirmacion : paqueteEnviado()
  EsperandoConfirmacion --> ConfirmacionRecibida : ACK recibido
  EsperandoConfirmacion --> ReintentandoConfirmacion : timeout (intentos <= 3)
  EsperandoConfirmacion --> FalloConfirmacion : timeout (intentos > 3)
  ReintentandoConfirmacion --> EnviandoPaqueteInicial
  FalloConfirmacion --> [*] : UC-011 falloCdM
  
  ConfirmacionRecibida --> Transmitiendo : idAsignado()
}

state Transmitiendo {
  [*] --> TransmisionActiva
  TransmisionActiva --> TransmitiendoUbicacion : intervaloUbicacion()
  TransmisionActiva --> TransmitiendoEvidencias : evidenciaPendiente()
  
  state TransmitiendoUbicacion {
    [*] --> EnviandoUbicacion
    EnviandoUbicacion --> UbicacionEnviada : éxito
    EnviandoUbicacion --> BufferLocal : pérdidaConexion
    BufferLocal --> Reconectando : intentoReconexion
    Reconectando --> EnviandoUbicacion : reconexionExitosa (intentos <= 3)
    Reconectando --> FalloGPS : reconexionFallida (intentos > 3)
    FalloGPS --> [*] : UC-011 falloGPS
  }
  
  state TransmitiendoEvidencias {
    [*] --> EnviandoEvidencia
    EnviandoEvidencia --> EvidenciaEnviada : éxito
    EnviandoEvidencia --> BufferEvidencia : pérdidaConexion
    BufferEvidencia --> ReconectandoEvidencia : intentoReconexion
    ReconectandoEvidencia --> EnviandoEvidencia : reconexionExitosa (intentos <= 3)
    ReconectandoEvidencia --> FalloEVD : reconexionFallida (intentos > 3)
    FalloEVD --> [*] : UC-011 falloEVD
  }
}

TransmitiendoUbicacion --> VerificandoEstado
TransmitiendoEvidencias --> VerificandoEstado

state VerificandoEstado {
  [*] --> EvaluandoAlarma
  EvaluandoAlarma --> TransmisionActiva : alarmaActiva
  EvaluandoAlarma --> CerrandoConexion : alarmaFinalizada
}

CerrandoConexion --> Desconectado

🧩 Identificación de Clases de Análisis (Patrón ECB)
Clase	Estereotipo	Responsabilidad
Usuario	A (Actor Secundario)	Receptor final de los mensajes SMS (contactos de emergencia, autoridades).
InterfazComunicacionesOffline	I (Interfaz)	Punto de entrada invocado por otros casos de uso (UC-009, UC-010) en modo fallo.
ControlComunicacionesOffline	C (Controlador)	Orquesta el flujo según el modo de fallo (falloCdM, falloCTO, falloGPS, falloEVD). Gestiona el envío de SMS, contacto con autoridades y monitoreo de reconexión.
ControlEnvioSMS	C (Controlador)	Envía mensajes SMS a través de la red celular. Maneja fallos de cobertura.
ControlLocalizacionAutoridades	C (Controlador)	Busca el número de contacto de las autoridades locales más cercanas a la última ubicación conocida (UC-013).
ControlMonitoreoConectividad	C (Controlador)	Monitorea periódicamente el estado de la conexión (internet y red celular) para reintentar comunicaciones pendientes.
ControlPersistenciaOffline	C (Controlador)	Guarda y recupera mensajes pendientes en almacenamiento local cuando no hay conectividad (UC-037).
GestorAlarma	C (Controlador)	Contexto de la alarma que proporciona datos del usuario, ubicación y mensaje predefinido.
ConfiguracionOffline	E (Entidad)	Almacena parámetros de reintento (intervalo de monitoreo de 60 segundos).
MensajePendiente	E (Entidad)	Representa un mensaje que no pudo ser enviado y debe ser almacenado para reintento.
AlmacenLocal	E (Entidad)	Persistencia de mensajes pendientes (relación con UC-037).

Enfocado en el estado de la gestión offline según el modo de fallo.

plantuml
@startuml

state DetectandoModo {
  [*] --> ModoCdM : modo == falloCdM
  [*] --> ModoCTO : modo == falloCTO
  [*] --> ModoGPS : modo == falloGPS
  [*] --> ModoEVD : modo == falloEVD
}

state ModoCdM {
  [*] --> EnviandoSMSContacto
  EnviandoSMSContacto --> EnviandoSMSCdM : contacto enviado o pendiente
  EnviandoSMSCdM --> Monitoreando : autoridades notificadas o pendiente
}

state ModoCTO {
  [*] --> EnviandoSMSContacto
  EnviandoSMSContacto --> Monitoreando : enviado o pendiente
}

state ModoGPS {
  [*] --> BuscandoAutoridades
  BuscandoAutoridades --> EnviandoSMSCdM : autoridades encontradas
  EnviandoSMSCdM --> Monitoreando : enviado o pendiente
}

state ModoEVD --> [*]

state Monitoreando {
  [*] --> VerificandoConectividad
  VerificandoConectividad --> ReintentandoEnvio : conectividadRestaurada (internet o celular)
  VerificandoConectividad --> Esperando : sinConectividad
  Esperando --> VerificandoConectividad : timeout 60s
  ReintentandoEnvio --> VerificandoConectividad : reintento completado o pendiente
}

state PendienteLocal {
  [*] --> Almacenado
  Almacenado --> ReintentandoEnvio : conectividadRestaurada
}

EnviandoSMSContacto --> PendienteLocal : falloEnvio
EnviandoSMSCdM --> PendienteLocal : falloEnvio

ControlPersistenciaSMS	C (Controlador)	Almacena mensajes en cola local cuando falla el envío (sin crédito, sin cobertura).
GestorAlarma	C (Controlador)	Proporciona contexto: nombre de usuario, ubicación, timestamp.
ConfiguracionSMS	E (Entidad)	Almacena límite de caracteres (160), formato de mensaje predefinido.
ColaSMS	E (Entidad)	Almacena mensajes SMS pendientes de envío con prioridad alta.
HistorialSMS	E (Entidad)	Registra cada envío de SMS con hora y estado (éxito, fallo, causa).

  CacheDesactualizada --> UsandoCacheAdvertencia : intentosAgotados

  AplicandoFiltros --> AmpliandoRadio : sinResultados
  AmpliandoRadio --> AplicandoFiltros : nuevoRadio <= 200km
  AmpliandoRadio --> UsandoGenericos : radioMaximoAlcanzado

  [*] --> Ordenando

  [*] --> DevolviendoGenericos

interfaz -> ctrlBusqueda : 1: buscarAutoridadesCercanas(coordenadas)

alt coordenadas == null
  ctrlBusqueda -> ctrlUbicacion : 2: obtenerUbicacionActual()
  ctrlUbicacion --> ctrlBusqueda : 3: coordenadas
  alt coordenadas == null
    ctrlBusqueda -> genericos : 4: obtenerNumerosGenericos()
    genericos --> ctrlBusqueda : 5: listaGenerica
    ctrlBusqueda -> historial : 6: registrarBusqueda(null, "fallback", false, 0)
    ctrlBusqueda --> interfaz : 7: listaGenerica
  end
end

ctrlBusqueda -> ctrlConectividad : 8: tieneInternet()
ctrlConectividad --> ctrlBusqueda : 9: conectado

alt conectado
  ctrlBusqueda -> api : 10: consultarAutoridades(coordenadas, radio)
  api --> ctrlBusqueda : 11: resultadosAPI
  ctrlBusqueda -> ctrlCache : 12: guardarCache(coordenadas, resultadosAPI)
  ctrlCache -> cache : 13: guardar(entrada)
  cache --> ctrlCache : 14: ok
else noConectado or errorAPI
  ctrlBusqueda -> ctrlCache : 10: obtenerCache(coordenadas)
  ctrlCache -> cache : 11: buscar(coordenadas)
  cache --> ctrlCache : 12: resultadosCache
  ctrlCache --> ctrlBusqueda : 13: resultadosCache (con antigüedad)
  
  alt resultadosCache == null
    ctrlBusqueda -> genericos : 14: obtenerNumerosGenericos()
    genericos --> ctrlBusqueda : 15: listaGenerica
  else antiguedad > 90 días
    ctrlBusqueda -> ctrlConectividad : 14: reintentarConexion(3)
    alt reconexionExitosa
      ctrlBusqueda -> api : 15: consultarAutoridades(coordenadas, radio)
      api --> ctrlBusqueda : 16: resultadosAPI
    else sinReconexion
      ctrlBusqueda -> ctrlBusqueda : 15: marcarCacheDesactualizada()
    end
  end
end

ctrlBusqueda -> config : 17: obtenerConfiguracion()
config --> ctrlBusqueda : 18: {radioDefault: 5, radioMax: 200, maxResultados: 5}

ctrlBusqueda -> ctrlBusqueda : 19: filtrarPorDistancia(resultados, coordenadas, radio)
ctrlBusqueda -> ctrlBusqueda : 20: filtrarPorTipo(resultados, tipoEmergencia)

alt resultadosFiltrados.isEmpty() and radio < 200
  loop mientras radio < 200 y resultados vacíos
    ctrlBusqueda -> ctrlBusqueda : 21: ampliarRadio(radio)
    ctrlBusqueda -> ctrlBusqueda : 22: filtrarPorDistancia(resultados, coordenadas, radio)
  end
end

alt resultadosFiltrados.isEmpty()
  ctrlBusqueda -> genericos : 23: obtenerNumerosGenericos()
  genericos --> ctrlBusqueda : 24: listaGenerica
else
  ctrlBusqueda -> ctrlBusqueda : 23: ordenarPorProximidad(resultados, coordenadas)
  ctrlBusqueda -> ctrlBusqueda : 24: limitarResultados(maxResultados)
end

ctrlBusqueda -> historial : 25: registrarBusqueda(coordenadas, origenDatos, exito, cantidad)
ctrlBusqueda --> interfaz : 26: listaFinal
